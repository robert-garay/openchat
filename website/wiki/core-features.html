Core features

Everyday chat features built into the native iOS experience.

Model picker and per-chat selection

Tap the model name in the chat navigation bar to open the model picker sheet. Each conversation remembers its own provider and model independently.

The picker shows provider logos, capability badges (vision, tools, reasoning, etc.), and supports fuzzy search. Star your favorite models to surface them at the top. Recently used models are ranked by usage.

Capability icons next to the model name in the toolbar give a quick read on what the current model supports.

Streaming Markdown, code blocks, and tables

Assistant replies render as rich Markdown while streaming. Supported formatting includes:

  • Headings, lists, blockquotes, and inline formatting
  • Syntax-highlighted code blocks
  • Tables
  • Selectable message text (long-press to copy)

Rendering uses SwiftStreamingMarkdown for smooth incremental updates as tokens arrive.

Image and document attachments

Attach images from your photo library or capture a new photo with the camera. Attachments appear above the composer before you send.

For models that support vision, images are sent to the provider with your message. If the current model does not support images, OpenChat shows a warning before sending.

Some models also support PDF document attachments. When supported, you can attach PDF files that the model can read as part of your message.

Chat history, search, and pinning

Swipe right from the chat screen (or tap the back chevron) to open the chat history drawer. Your conversations are listed by recency, with pinned chats shown in a separate section at the top.

Use the Search chats field at the bottom of the drawer to filter by title or last message preview.

Long-press a conversation (or use the context menu) to:

  • Pin or unpin a chat
  • Rename a chat
  • Delete a chat

Chats are auto-titled from your first message unless you set a custom title. Tap the compose button in the drawer to start a new chat.

Temporary chats

Tap the ghost icon in the top-right toolbar to start or exit a temporary chat. Temporary chats:

  • Are labeled "Temporary Chat" in the navigation bar
  • Do not appear in the chat history drawer
  • Are not persisted when you leave them
  • Do not use memory or allow rule proposals

Use temporary chats when you want a one-off conversation that leaves no trace in your history.

Light and dark mode

Open Settings → Appearance → Theme and choose:

  • System — follow your iOS appearance setting
  • Light — always light
  • Dark — always dark

The theme applies across the app including sheets and popovers.
