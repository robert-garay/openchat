Why OpenChat

Built for how you actually use AI

1

Pay for performance, not a logo

Route through OpenRouter to DeepSeek, Qwen, Mistral, or Llama. Pick a flagship only when the task needs it.

2

Bring your own key

No OpenChat account. API keys live in your iOS Keychain. The app talks directly to providers you configure.

3

Your data stays local

Chats, rules, memory, and skills are stored on your device with SwiftData. No OpenChat servers. No analytics SDKs.

Features

Everything you need in one native app

Streaming Markdown & code

Rich assistant replies with tables, syntax highlighting, and selectable text.

Live model catalogs

Fresh model lists from supported providers and OpenRouter's public catalog.

Web search

Optional search via Tavily, Exa, Brave, Serper, or SerpAPI. Use your own API keys.

Rules & memory

Global and per-chat rules. Editable on-device memory across conversations.

Skills (beta)

Reusable prompt shortcuts invoked with / in the composer.

Background generation

Replies finish while you're away. Live Activity and a local notification when done.

Vision attachments

Send photos from your library or camera to vision-capable models.

Light & dark mode

System, light, or dark. Matches the native iOS look.

Privacy

Private by design

OpenChat has no backend, no first-party analytics, no ads, and no tracking. When you send a message, data goes directly from your device to the AI or search provider you chose.

No OpenChat servers No analytics SDKs No cookies on this site Open source (MIT)
